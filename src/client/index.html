    Controles

    • PC: WASD o flechas para moverte, ratón para apuntar, clic o espacio para disparar, teclas 1 a 3 para objetos, M para silenciar.
    • Móvil: joystick abajo a la izquierda, botón FUEGO abajo a la derecha. Los controles aparecen solos.
    • Objetivo: abre los 3 nodos (BREACH) y luego lleven a todo el equipo a la salida (SYNC).
